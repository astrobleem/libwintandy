TPLAY WINDOWS XT LAUNCHER

TPLAY.C, TPLAYPOL.H and generated SOUNDID.H in libtandywin/AUDIO/SOURCE
match the maintained launcher in OEMSound src/win30/LAUNCH. The current
consumer installation is OEMSound's native TWSETUP.EXE. Run it in plain DOS,
then C:\WINAMP\GO. Setup installs the player, canonical SOUND.DRV and all
required DLLs and launch helpers, and updates Windows automatically.

HPXY.DRV and XRSYNC.DRV use the included exact 16 KB normal-640KB reservation
helper. CGA needs no reservation. Other qualified Tandy profiles are explicit
in TPLAYPOL.H; unknown names refuse. ROM markers, real-mode SYSTEM identity,
IRQ ownership, canonical SOUND identity and bridge ownership checks remain.
Generated SOUNDID.H binds consumers to the canonical native SOUND artifact.

TPLAY starts Windows directly with absolute paths, reserves or reuses video
memory without duplicate chaining, and removes its owned bridge after normal
Windows return. The same installed SOUND module serves legacy queues,
Windows alerts, raw PSG owners and PIT tools. Apps resolve its extensions
from the active SOUND module rather than loading another driver.

OEMSound tools/WINAMP contains package generation/verification and exact
source/build/runtime receipts. Native testing is separate from public host
CI. Historical runtime archives and test records retain their original
binary identities and scope.
