TPLAY WINDOWS XT LAUNCHER

TPLAY.C and TPLAYPOL.H in libtandywin/AUDIO/SOURCE are the canonical source
for the Windows XT launcher shipped with Tandy Winamp XT1:
https://github.com/astrobleem/oemsound-tandy/releases/tag/tandy-winamp-xt1.20261024

HPXY.DRV and the reviewed XRSYNC.DRV use the exact 16 KB normal 640 KB reservation
helper; CGA needs no reservation. The explicit historical Tandy names retain
their same guard. Unknown displays refuse. EX/HX ROM, ROM IRQ ownership,
paired SYSTEM/TSOUND and bridge parent/cleanup checks remain intact.

The ready-to-run Winamp package includes RESERVE.COM and the exact tested
TSOUND.DRV with corresponding source and notices. Its guide explains selecting
TSOUND.DRV explicitly in the existing Windows 3.0 real-mode profile, then
running TPLAY directly from plain DOS. No separate display launcher is chained.

OEMSound's LAUNCH/TESTS.JSON and EVIDENCE contain 49 host policy checks,
31 native preflight cases, actual XRSYNC playback during graphics activity,
stop, sound release, normal exit/bridge cleanup and the direct sound-install
check. Earlier HPXY/CGA, reservation reuse and failed-start receipts retain
their recorded runtime identities. CI checks exact-head source/packet pins;
native execution uses the installed emulator and disposable Windows profiles.
Historical runtime archives in this repository remain unchanged.
