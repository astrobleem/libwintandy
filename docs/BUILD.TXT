Host UI checks:
  python libtandywin/TESTS/RUN.PY --cc <host-cc>
Host actual-source audio checks (MSYS2 UCRT64 GCC on Windows):
  python libtandywin/AUDIO/HOST/RUN.PY
Host layout/typed facade checks:
  python libtandywin/AUDIO/TESTS/FACADE/RUN.PY
The runners prefix their matching compiler directory to process-local PATH;
never download individual compiler DLLs or change global PATH for these tests.
This machine lacks libubsan. Recorded source tests are unsanitized, and raw
hardware is mocked. Native execution/IRQ/Win16 ABI are separate gates.

Win16 UI: use caller-supplied licensed MSC6 and Windows3.0 headers/libraries.
  CL /nologo /c /G0 /Gw /AS /W3 /Od /I<owned-include> LTWUI.C
Link LTWUI.OBJ once with the caller, using the same memory model. Include
WINDOWS.H before LWTANDY.H. TShell keeps the same object and only adds the new
header to its existing build copy list.

Fresh audio build (requires an explicit emulator lease and external tools):
  python libtandywin/AUDIO/BUILD/PLAYER30.PY --dosbox <DOSBox-X> 
    --toolchain <owned-MSC6-DDK-root> --out <new-private-output>
This builds MINIPLAY, RAWQA, provider DLLs and TBRIDGE, marks Win16 modules for
Windows3.0, records exact source/runtime hashes, and certifies compile/link
only. It has not been run at this source checkpoint. The full private R4
erratum build also rebuilds QCHIME/QXP/QEXIT/QPSG/QMOUTH before those binaries
may ship. No compiler, SDK/import library or emulator is provided.
